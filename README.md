**ONEASZ** adalah platform digital korporat yang dirancang sebagai pusat solusi teknologi strategis. Mengusung konsep *Neo-Brutalist UI*, sistem ini mengintegrasikan layanan *Custom Development*, *Infrastruktur Cloud*, dan *System Reliability* dalam satu ekosistem visual yang tajam, berani, dan presisi.

---

## 🚀 Fitur Utama & Keunggulan Digital

Proyek ini dibangun untuk mendemonstrasikan kapabilitas teknologi tingkat lanjut dengan fokus pada tiga pilar utama:

### ⚡ 1. Scalable & High-Performance Architecture
* **Custom Web Development:** Arsitektur kode yang bersih menggunakan Django, dirancang untuk skalabilitas pertumbuhan bisnis tanpa batas.
* **Enterprise-Grade Infrastructure:** Fokus pada penyediaan solusi *Cloud & Infrastructure* yang mampu menangani beban operasional tinggi dengan latensi rendah.
* **Dynamic Component Loading:** Implementasi transisi halus dan pemuatan data asinkron menggunakan Alpine.js.

### 🔒 2. Security & Reliability System
* **Full Stack Security:** Menjamin keamanan komprehensif mulai dari level aplikasi hingga arsitektur *Cloud Server* terdalam.
* **System Integrity:** Dirancang dengan prinsip *DevOps & Reliability* untuk memastikan *uptime* maksimal bagi layanan kritis perusahaan.
* **Data Validation:** Form konsultasi cerdas dengan proteksi CSRF dan validasi server-side yang ketat.

### 🏅 3. Professional Validation Hub
* **Certification Gallery:** Menampilkan rekam jejak kompetensi resmi (PDF) secara interaktif, mencakup bidang Cloud Computing, Cyber Security, dan Software Architecture.
* **Direct Access Connectivity:** Integrasi instan "One-Click" ke aplikasi WhatsApp dan Gmail dengan parameter pesan otomatis untuk mempercepat konversi bisnis.

## ⚙️ Panduan Instalasi Lokal

1.  **Clone Repositori:**
    ```bash
    git clone [https://github.com/username/oneasz-project.git](https://github.com/username/oneasz-project.git)
    cd oneasz-project
    ```

2.  **Environment Setup:**
    ```bash
    python -m venv env
    source env/bin/activate  # Windows: .\env\Scripts\activate
    pip install -r requirements.txt
    ```

3.  **WWW Redirect & Host Configuration:**
    Pastikan `ALLOWED_HOSTS` di `settings.py` sudah mencakup domain utama dan `www`.
    ```python
    ALLOWED_HOSTS = ['oneasz.com', '[www.oneasz.com](https://www.oneasz.com)', '127.0.0.1']
    ```

4.  **Running Server:**
    ```bash
    python manage.py runserver
    ```
